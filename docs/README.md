## 🎯 **What is NGBSE 20.1?**

NGBSE 20.1 is a comprehensive Open-Source Intelligence (OSINT) engine that:

- **Collects intelligence** from multiple sources (web, threat feeds, infrastructure, code repositories)
- **Identifies blind spots** in your intelligence gathering
- **Generates insights** using AI-powered analysis (BALLM)
- **Exports results** in professional formats (STIX 2.1, DOCX reports)

## 🔧 **Key Features**

### **OSINT Collectors**
- **HttpWeb**: Web scraping and content analysis
- **LeakIX**: Data breach intelligence
- **Shodan**: IoT and infrastructure intelligence
- **Censys**: Network and SSL intelligence
- **URLScan**: Threat intelligence
- **GitHub**: Code repository intelligence
- **News**: Recent developments and threat intelligence

### **Pipeline Features**
- **Multi-source collection** with automatic failover
- **Epistemic scoring** for quality assessment
- **Blindspot analysis** for gap identification
- **BALLM integration** for AI-powered insights
- **Professional reporting** in multiple formats

### **Export Formats**
- **STIX 2.1** for threat intelligence platforms
- **DOCX reports** for executive presentations
- **JSON data** for custom analysis
- **Manifest files** for chain of custody

## 📋 **Prerequisites**

### **Required**
- Python 3.11+ or Docker
- At least one OSINT API key

### **Recommended**
- Multiple API keys for comprehensive coverage
- LLM API key for BALLM insights
- 4GB+ RAM for large collections
